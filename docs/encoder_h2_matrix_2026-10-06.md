# H2補正：電流・方向を変えた再現性確認（2026-10-06）

**Iq=±8、±12、±15 Aでは、両方向・2回の比較すべてで補正ONのId 2/rev振幅が小さくなった。**
低減率は約44～95%。一方、±4 Aでは低減を確認できず、+4 Aの再測定には未始動もあった。
全電流域で一様に改善すると結論づけず、現状は8～15 Aで低減効果の再現性を確認したと判断する。

## 条件と方法

- 負荷あり、COM6、Release、Id指令0 A。Iqの符号を変えて正逆を試験。
- FW、PIゲイン、Flash、補正係数は変更していない。
- direction=+1、offset=1.961604 rad、a2=−0.053652、b2=+0.060009 rad_elec、gain=+1。
- 各運転の間でPWM停止、ADCログ終了。FOC開始時の既存静止判定を維持。
- 1回目は各14.718～14.975秒。正方向OFF→ON、逆方向ON→OFF。
- 2回目は各9.701～9.907秒。順序を逆にした。±8/12/15 Aは全条件完了。
  +4 AのONは完了したが、OFFは未始動で比較不能。−4 Aの2回目は実施していない。
- `adc 200`（約100 Hz）。起動後2秒を除外し、停止直前50 msも除外。
- raw機械角を使い、`Id=c+a*cos(2θm)+b*sin(2θm)`を最小二乗フィット。
  表の振幅は`hypot(a,b)`、片振幅[mA]。RMSやpeak-to-peakではない。

## Idの2/rev振幅

| Iq [A] | 1回目 OFF→ON [mA] | 2回目 OFF→ON [mA] | 低減率（1回目 / 2回目） |
|---|---:|---:|---:|
| +4 | 0.336→4.935 | OFF未始動 / ON 4.931 | 低減なし / 比較不能 |
| −4 | 1.039→1.923 | 未実施 | 低減なし |
| +8 | 19.252→4.866 | 17.325→9.738 | 74.7% / 43.8% |
| −8 | 23.321→2.393 | 22.349→1.608 | 89.7% / 92.8% |
| +12 | 32.863→5.124 | 29.461→7.924 | 84.4% / 73.1% |
| −12 | 37.964→6.957 | 48.742→4.223 | 81.7% / 91.3% |
| +15 | 51.551→12.243 | 43.274→12.830 | 76.3% / 70.4% |
| −15 | 65.419→3.583 | 64.294→4.817 | 94.5% / 92.5% |

8～15 Aでは順序を逆にしても低減が再現した。ただし残留振幅は方向・試行で異なり、
特に+8 Aは4.87～9.74 mAと変動する。一定の残留精度を保証する結果ではない。
4 Aは元の2/rev成分が非常に小さく、今回の回転データではONの方が数mA大きかった。
「低電流でも必ず有利」とは扱わない。未始動は約4 Aの電流追従・rpm約0を確認しており、
角度範囲が不足するためフィットを拒否した。始動しなかった原因の特定は行っていない。

## 回転数・保護・ログ

定常平均rpmは+4で約62～64、−4で約−67～−70、+8で約157～163、−8で約−171～−180、
+12で約246～254、−12で約−277～−286、+15で約317～324、−15で約−358～−366。
同一IqのOFF/ONでも速度・温度は完全一致していない。

- 有効記録は29運転。全採用ログでsample差分200、角度/dqの時刻一致、log_overrun=0。
- 採用運転の停止理由はuser stop。保護停止なし、観測したPI saturatedはすべて0。
- 相電流ピーク最大15.576 A、NTC表示最大43.34 ℃、ADC制御処理最大32.700 µs。
- UART RX errors/overrun/queue_drops/long_lines=0。
- 補正量と係数式の最大差0.000567 rad、`wrap(base+correction)`との最大差0.001186 rad。
  いずれもログ小数3桁の丸めに整合。OFFでは補正量ゼロ。
- 最終エンコーダーspi/parity/sensor/timeout=0、first faultなし。
  busy_ticks=2363884、decode_waits=1651857は累積しており、取得見送り自体は存在する。

15 Aまでの追加指示に合わせ、ホストの指令許容範囲を±15 Aへ拡張した。
ホスト相電流ピーク停止閾値は`max(15 A, abs(Iq)+2 A)`（15 A指令では17 A）。
ホスト速度停止450 rpm、開始前NTC上限50 ℃。FWの20 A相電流保護・600 rpm制限は変更していない。
NTCは巻線温度そのものではなく、この試験は連続定格・熱平衡を保証しない。

## 除外した記録と測定スクリプトの修正

1. 最初の+4 A：正常起動の応答が30 ms以内に揃わず、ホストが停止。起動応答待ちを150 msへ変更。
2. 最初の−12 A ON：状態表示が80 ms以内に揃わずホストが停止。
   生ログでは停止要求前もrunning/fault=none。分割応答の末尾まで最大4回×80 ms追加受信するよう修正。
3. 最初の−15 A ON：1.672～1.772秒付近に約100 msの受信欠落。FW overrunとUART RXカウンターは0。
   原因未特定で、全体を比較から除外。取り直しは欠落なし。
4. 2回目の+4 A OFF：電流は追従したがほぼ静止。2/revフィット不能として除外。

除外記録はそれぞれ`build/h2_start_ack_timeout_20261006.log`、
`h2_status_ack_timeout_20261006.log`、`h2_m15_on_capture_gap_20261006.log`、
`h2_p4_off_no_rotation_20261006.log`に保持した。失敗を欠落のない測定として扱っていない。

## 記録と最終状態

生ログは`build/h2_matrix_r{1,2}_{p,m}{4,8,12,15}_{off,on}_20261006.log`。
各採用運転に同名JSON、全体集計は`build/h2_matrix_summary_20261006.json`と`.txt`。
解析は`tools/analyze_h2_endurance.py`、集計は`tools/summarize_h2_matrix.py`。
負電流の解析と短い時間区間に対応するため解析スクリプトも更新した。

終了時はPWM停止、ADCログidle、H2 OFF、gain=+1、COM6解放済み。
保存係数、direction/offset、stored=yesは維持。最終状態は`build/h2_matrix_final_20261006.log`。

今回確認したのは閉ループIdの2/rev低減と補正演算の整合性であり、独立した角度基準による
エンコーダー絶対精度ではない。高電流域では現係数・gain=+1を維持する根拠が得られたが、
低電流だけ別係数や自動切替にする変更は、この結果だけでは行わない。
