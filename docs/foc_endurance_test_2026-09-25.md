# FOC連続運転・繰り返し起動停止（2026-09-25）

Release実機で5分間の連続運転と20回の起動停止を完了しました。保護停止、通信エラー増加、ADCログ欠落はありませんでした。今回、FWやCubeMX設定の変更・再書込みは行っていません。

## 条件と手順

- COM11、921600 bps / 8N1。前回UART・ADCログ試験のReleaseを使用。
- 指令Vd=0 V / Vq=+0.4 V、FOC電流保護5 A、既存の校正値を使用。毎回`foc voltage 0 0.4`で再設定。
- 初期VM=24.242 V。今回記録したVMは24.209～24.285 V。
- `foc start`後、running・fault=noneを確認し、`adc 100`で約200 Hzログを開始。
- 連続運転：ログ開始応答後から300秒保持。5秒ごとにFOC、UART、エンコーダー、ADC、VMの状態を記録。
- 起動停止：停止後5秒待機→再設定・起動→ログ開始後5秒保持→状態確認→`adc stop`→`stop`を20回。コマンド応答待ちも含むため、各回の実運転時間は5秒より長くなります。
- 各停止後にも状態を確認。保護停止や応答異常があれば以降の試験を中止するホストスクリプトを使用。
- 実施時刻：07:27:47～07:37:35頃（JST）。正方向のみ。逆方向、Debug、負荷条件変更、数時間規模の耐久性は今回の対象外です。
