# 校正再現性試験（2026-09-23）

N5065、7極対、VM約24 V、校正電圧0.4 V、電流保護5 A。
FW・校正パラメーターは変更せず、シリアルで10回測定した。
最初の3回は自然停止位置から連続実行。4～9回目は校正の途中で明示的にstopし、
約1秒待ってローター開始位置を変えてから再校正。10回目は直前の自然停止位置から実行した。
開始角は通電前のAS5047P機械角。途中停止は設定済みの電流保護下で実施した。

結果は成功5/10、戻り位置誤差4/10、移動量不一致1/10。
成功時の相順はすべて+1。成功値の幅は2.055電気deg。
最初の3回だけでは最大差約0.037電気degだったが、開始位置変更後は不成立が増えた。
戻り位置誤差の許容値0.15 rad（約8.59電気deg）は緩和していない。
最大電流2.463 A、過電流停止なし、各試行終了時にPWM停止とUART errors/overrun=0を確認した。

開始位置への依存が疑われ、現状の校正は十分な再現性があるとは判断できない。
静止摩擦・コギング、初期整列不足、低電圧時の実効電圧誤差などは候補だが、今回の試験だけでは原因を特定できない。
移動量不一致は期待移動量からの逸脱を示し、極対数が誤っていると断定する結果ではない。
次は初期整列・往復各端点の角度と電流を記録し、進入方向を揃えた整列や保持時間の効果を調べる。
FOC通電前にこの再現性を改善し、許容誤差を広げて成功扱いにすることは避ける。

試験値のFlash保存は行っていない。従来保存値direction=+1、offset=5.150699 radを維持。
生ログと試験スクリプトはbuild/cal_repeatability/（ビルド成果物、Git管理外）。


## 追加調査と同方向からの予備整列

磁気エンコーダーの物理的な誤差があり得るという申告を受け、各保持終了時の
平均機械角、保持中の角度幅、直近4電流を出力する診断を追加した。
従来手順の追加2回も不成立。保持中の幅は約1～1.5電気degに対し、戻り位置は約10～23電気degずれた。
静的な位置依存のセンサー誤差だけなら、同一の物理的位置へ戻る際には同じ読み値になるはずなので、
これだけを原因とは断定できない。静止摩擦・進入方向の影響、測定の時間依存性なども候補となる。

初期引き込み後、負方向に1電気回転する予備走査と保持（stage 8/9）を追加した。
その位置を初期測定点とし、往復後にも同じ負方向から近づく。0.4 V、5 A、保持時間、
戻り誤差の閾値0.15 radは変更していない。校正全体は約16秒へ延長。
この手順は各試行の機械的な基準位置を移動させるため、停止位置は開始前と同じとは限らない。

変更後は8/8回成功。戻り誤差の最大絶対値は約0.157電気deg。
追加stage 8でstop、stage 9でcal stopを試し、PWM停止・ADC idleを確認。
Release/Debugビルドと実機セルフテスト586項目も成功した。

一方、成功したoffsetにも位置に応じて最大約7.92電気deg（7極対換算で約1.13機械deg）の幅が残った。
同じ位置付近の13回目/19回目は約0.024電気deg差で、位置に応じた偏りは再現している。
ユーザー申告のエンコーダー非直線性と整合し得るが、モーターの位置依存の整列誤差も含むため、
外部の角度基準なしにはエンコーダーだけの誤差とは分離できない。
この値は外部基準に対する絶対角度精度の測定結果ではない。

改善したのは往復の再現性。単一offsetで全周の誤差を除去できることは確認できていない。
FOC通電前に、磁石の偏心・傾き・取付を確認するか、全周の誤差測定と補正方式を検討する必要がある。
電流PIや誤差補正テーブルは今回追加していない。Flash校正値も上書きしていない。

## 校正電圧の比較（2026-09-23～24）

同方向の予備整列を使い、0.45 Vと0.50 Vでそれぞれ7回（7つの整列位置）を測定。
電流保護5 A、走査/保持時間、許容誤差は変更せず、Flash保存もしなかった。
0.40 Vは前節の8回（7位置、1位置重複）を比較基準にした。
各位置は機械角1周内の対応する整列点だが、電圧で整列位置自体が少し変わるため、厳密に同一の機械角ではない。
温度は統制しておらず、各電圧の各位置1回が基本であるため、統計的な精度保証ではない。

0.40→0.50 Vで位置間の幅は約19%減少したが、約6.43電気deg（約0.92機械deg）が残った。
最大電流は約2.50→3.46 A（約39%増）で、今回の電圧比較では過電流停止なし。
各試行終了時のPWM停止とUART errors/overrun=0も確認した。

電圧に依存する成分があることは確認できたが、電圧を上げるだけで位置依存誤差は解消しなかった。
摩擦・保持トルクによる整列誤差の寄与は考えられる。電圧ごとに実際の整列位置が変わるため、
エンコーダーの非直線性や電流に依存する測定誤差との切り分けまではできていない。
引き続き磁石取付の確認や、外部角度基準を使った全周誤差測定が必要。
今回の測定を根拠に保護閾値を上げたり、補正テーブルを作成したりはしていない。

試験後は校正電圧0.40 Vへ戻し、Releaseを再書き込み。
既存Flash校正値direction=+1 / offset=5.150699 radを維持する。

外部角度基準なしでモーターとエンコーダーそれぞれの誤差を分離することはできない。

## 採用パラメーター（2026-09-24）

比較試験後の決定として、校正電圧1.0 V、校正過電流閾値10 Aを既定値に採用した。
将来のFOC通常運転用閾値は5 Aを維持し、校正には適用しない。
従来の二重判定と「校正閾値≦通常運転閾値」の設定チェックを解消した。
電流制御やFOC運転は追加していない。試験後に0.4 V/5 Aへ戻したという上記の記録は履歴であり、現行設定ではない。
